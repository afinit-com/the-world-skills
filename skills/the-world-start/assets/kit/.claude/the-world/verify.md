# Claude compatibility wrapper

This path remains for existing Claude commands. Verifying the harness is
`docs/verify.md`: run `uv run python harness.py --verify-plan` and follow its six steps,
from the local checks to a real thread and what it left behind, ending in a report that
keeps what was confirmed apart from what was not. In a browser, send a new message only
when the person allowed it in this conversation, and never press an approve or deny
button. Read `WORLD.md` for the cast and vocabulary and `docs/philosophy.md` for why each
boundary exists.
